# AI Personal Learning Path Generator — MVP

## Files
- `index.html` — structure and accessible UI
- `style.css` — responsive visual system, dark/light themes, UI modes and animations
- `script.js` — demo data, onboarding, chat, progress, check-ins, notes processing, tasks and customization

## Run locally
1. Put all three files in the same folder.
2. Open `index.html` directly in a modern browser, or run a local server:
   - Python: `python3 -m http.server 8000`
   - Then open `http://localhost:8000`
3. No backend, npm, React, or external dependency is required.

## Demo flow
Use **Edit profile** for onboarding, **Analyze my path** for the AI state animation, tabs in **Showing**, the Notes/PDF upload demo, the explanation slider, check-in controls, task checkboxes, UI modes, theme and the chat input.
